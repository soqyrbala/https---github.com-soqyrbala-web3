# Steppe & Peaks – Midterm Project

**Topic:** travel agency website about Kazakhstan.

**Pages:** index, about, destinations (table), gallery (CSS Grid), contact (form).

**Features:** semantic HTML5, sticky navbar on all pages, Flexbox (feature cards), CSS Grid (gallery),
positioning (sticky / relative / absolute), media queries (992px and 576px), Bootstrap 5 grid + utilities.

**Live site:** https://soqyrbala.github.io/web3/
